# 1. 概述

## 1.1 建设背景

业务当前通过多份线下 Excel 管理静态材料、机电材料、战略备料及专项备料数据，数据来源、处理方案、责任归属和消耗进度缺少统一沉淀与追溯。IOC 需建设“静态材料分析”，接收外围系统按月提供的 SAP 基础数据，并结合业务导入及页面维护，形成报表查询、消耗跟踪、风险预警和分析看板。

本需求覆盖以下三类入口：

- 报表中心 > 静态材料分析：7 个报表入口。
- 分析看板 > 静态材料处理跟踪分析：总体、警报、处理方案和明细分析。
- 配置中心 > 静态材料配置：静态材料与机电材料的处理方案、静态原因配置。

## 1.2 建设目标

1. 统一承接外围系统每月 1 日传输的静态材料分析基础数据，并保留版本和异常记录。
2. 所有物料按“工厂编码 + 物料编码”独立展示和维护，不再合并不同工厂数据。
3. 支持业务通过标准模板补充维护字段，并完整追溯处理方案和处理意见的变更。
4. 由新增静态物料表统一向静态材料、机电材料跟踪消耗报表及分析看板供数。
5. 通过静态月数、留存率和处理方案形成风险分级和明细下钻。

## 1.3 范围边界

**本期范围**

- 四类外围数据集的月度接收、校验、版本留存和异常通知。
- 7 个静态材料分析报表的查询、导入、导出、分页及历史查看。
- 静态材料处理跟踪分析看板。
- 处理方案、静态原因、责任单位、方案制定部门及开发类型的业务维护。
- 导入模板下载、模板字段校验、错误反馈和变更次数控制。

**不在本期范围**

- IOC 回写 SAP。
- 替代业务审批流程。
- 在计算口径未确认前将暂定公式固化为不可调整逻辑。

# 2. 总体业务规则

## 2.1 数据流转

```text
外围系统每月1日生成全量数据
  -> IOC接收并校验批次、月份、字段和唯一键
  -> 生成接收版本及成功/失败结果
  -> 写入对应月度快照
  -> 新增静态物料表形成静态/机电基础记录
  -> 业务下载待维护数据并导入处理方案、责任单位等字段
  -> 业务维护开发类型及配置项
  -> 跟踪消耗报表、警报表和分析看板查询与下钻
```

## 2.2 数据粒度与覆盖规则

1. 静态材料相关数据一律按“工厂编码 + 物料编码”分开存储、展示、导入和统计。
2. 同一物料位于不同工厂时分别计为不同记录，不得合并数量或互相覆盖维护结果。
3. 工厂描述、物料描述用于展示和导入核对，不参与唯一键匹配。
4. 业务维护字段与接口字段同名时，除非另有明确覆盖规则，否则保留已生效业务维护值。
5. 新增静态物料表是静态材料跟踪消耗报表和机电材料跟踪消耗报表的数据来源；后续需求和开发不得再为两张消耗报表建立独立手工台账。

## 2.3 日期与查询规则

1. 静态提出日期固定为每月 1 日，例如 2026 年 8 月数据记录为 `2026-08-01`。
2. 报表日期筛选按月选择，默认当前月。
3. 日期筛选提供“全部时间”选项，选择后查询所有已生效月份的数据。
4. 分析看板使用当前最新生效数据，不提供历史月份查询；历史数据在对应报表中查询。

# 3. 外围系统数据集成

## 3.1 接口数据集

| 数据集 | 频率 | 目标功能 | 已确认规则 |
| --- | --- | --- | --- |
| 战略和专项材料 | 每月 1 日 | 战略备料表、专项备料表 | 全量更新，按版本留存。 |
| 战略和专项材料基础数据 | 每月 1 日 | 基础数据报表及备料时月均消耗量 | 全量更新，按版本留存。 |
| 静态材料 | 每月 1 日 | 新增静态物料表-静态材料 | 每月只允许一次成功接收。 |
| 机电材料 | 每月 1 日 | 新增静态物料表-机电材料 | 每月只允许一次成功接收。 |

## 3.2 接收、版本和重复传输

1. 战略/专项相关数据每次成功全量更新均保存版本号，支持追溯历史版本。
2. 新增静态材料数据每月只允许形成一份生效数据，不得因重复传输产生重复业务记录。
3. 外围系统传输方式、API、批次失败、重试和幂等机制由开发任务定义，不在本需求文档中展开。
4. 不建设 Yolink 通知。

## 3.3 战略/专项备料时月均消耗量

1. `备料时3月月均消耗量` 由 SAP 随战略和专项材料基础数据全量接口一并提供。
2. SAP 按物料首次维护为战略或专项材料的时间，向前取 3 个月计算平均消耗量。
3. IOC 在一个连续维护周期内固定展示首次接收的对应值；后续全量版本持续传值时不覆盖该周期展示基准值，但保留接口原始值。
4. 物料从一次成功全量版本中移除后，当前连续维护周期结束；后续重新纳入时，以新周期首次接收值重新冻结。
5. 战略和专项数据只按物料编码处理；战略、专项类型分别识别连续维护周期，不增加工厂维度。

## 3.4 业务数据异常边界

| 异常场景 | 已确认处理 |
| --- | --- |
| 新增静态材料同月重复传输 | 不得产生重复生效数据，具体技术处理由开发任务定义。 |
| 业务导入缺少必填字段或字段类型错误 | 阻止问题数据导入并展示字段级错误。 |
| 计算依赖字段缺失 | 计算值暂不生成并记录数据异常。 |

# 4. 报表中心 - 静态材料分析

## 4.1 菜单结构

在“报表中心”中新建与“定制”同级风格的子菜单“静态材料分析”，下设 7 个入口：

| 序号 | 报表 | 主要数据来源 |
| --- | --- | --- |
| 1 | 战略备料表 | 战略和专项材料、战略和专项材料基础数据、IOC 库存。 |
| 2 | 专项备料表 | 战略和专项材料、战略和专项材料基础数据、IOC 库存。 |
| 3 | 战略和专项材料基础数据 | 战略和专项材料基础数据接口。 |
| 4 | 新增静态物料表 | 静态材料、机电材料接口及业务维护数据。 |
| 5 | 机电材料跟踪消耗报表 | 新增静态物料表的机电材料数据。 |
| 6 | 静态材料跟踪消耗报表 | 新增静态物料表的静态材料数据。 |
| 7 | 静态物料警报表 | 新增静态物料表、消耗数据及警报规则。 |

报表统一沿用现有报表中心的查询区、工具栏、表格、固定列、横向滚动和分页样式。查询区与表格之间不保留大块空白，表格应尽量占满可用高度；工具栏不展示“查询结果”文字。

## 4.2 战略备料表、专项备料表

两张报表字段、查询和交互一致，仅材料类型不同。

**查询条件**：材料类别、物料编码、物料描述、备料天数、可供应天数。

**列表字段**：材料类别、物料编码、物料描述、备料时3月月均消耗量、备料天数、当前库存、近3月月均消耗量、可供应天数、超量备料。

**已确认规则**

- 报表按物料编码汇总全部工厂统计，不展示和筛选工厂编码、工厂描述。
- 当前库存从 IOC 库存数据获取，按物料编码汇总各工厂库存。
- 近3月月均消耗量由 IOC 每日计算一次，页面展示最近一次计算结果。
- 当前库存由 IOC 每日计算一次，按物料编码汇总各工厂后刷新，页面展示最近一次计算结果。
- 近3月月均消耗量、超量备料按物料编码汇总各工厂计算；可供应天数以汇总当前库存 ÷ 汇总近3月月均消耗量计算。
- 两张报表在导出按钮左侧展示当天数据更新时间，格式为 `YYYY-MM-DD HH24:MI:SS`，取最近一次 SAP 集成及 IOC 计算完成时间；“数据更新时间：”使用黑色字体，具体时间使用红色字体。
- 可供应天数暂按 `当前库存 / 近3月月均消耗量` 计算。
- 超量备料 = `当前库存 - 近3月月均消耗量 × 备料天数`。
- 备料时3月月均消耗量遵循第 3.3 节的连续维护周期冻结规则。
- 默认展示当前生效版本；历史版本永久保留并只读查看。

## 4.3 战略和专项材料基础数据

1. 展示外围系统传输的战略、专项材料基础明细，并为两张备料报表供数。
2. 每日根据 SAP 集成的全量基础数据同步当前展示范围：新增物料加入当前数据，SAP 已移除的物料从当前有效数据中删除；历史版本及其物料快照永久保留并只读查看。
2. 支持查询、重置、导出、分页及版本追溯。
3. 接口每次全量传输均包含备料时3月月均消耗量；原始版本值保留，报表展示值按冻结规则产生。
4. 完整查询条件和列表字段在读取接口文档后逐项补充确认；该报表仅支持查询和导出，不提供人工维护。

# 5. 计算与衍生字段

## 5.1 材料类别判定

本规则用于生成报表字段“材料类别”（业务口径中也称“材料类型”）。系统根据物料组编码前缀和物料组描述的层级值按以下优先顺序判断：

1. **皮料**：物料组编码以 `RA11` 开头时，材料类别取物料组描述第 3 层值。
2. **包装物**：物料组编码以 `RB` 开头时，材料类别取物料组描述第 1 层值。
3. **低耗物料**：物料组编码以 `RC` 开头时，材料类别取物料组描述第 1 层值。
4. **其他物料**：不符合以上前缀时，材料类别取物料组描述第 2 层值。

物料组描述使用 `/` 分隔层级。皮料示例如下：

| 物料组编码 | 物料组描述 | 材料类别 |
| --- | --- | --- |
| RA110100 | 原材料/皮/真皮 | 真皮 |
| RA110200 | 原材料/皮/仿皮 | 仿皮 |
| RA110300 | 原材料/皮/超纤皮 | 超纤皮 |
| RA110400 | 原材料/皮/西皮 | 西皮 |
| RA110500 | 原材料/皮/装饰皮 | 装饰皮 |
| RA110600 | 原材料/皮/改色仿皮 | 改色仿皮 |
| RA110700 | 原材料/皮/欧皮 | 欧皮 |

判定时先匹配 `RA11`，再匹配 `RB`、`RC`，最后执行其他物料规则。物料组描述缺少规则要求的层级时，不生成材料类别，并记录数据异常。

- 静态材料：采购大于需求、计划大于需求、样品采购、首批采购、起订量采购、停单扣款、报废拆件、材料退回、物料替换、分厂需求、计划取消、业务调整、设备报废、常规备料、战略备料、专项备料。
- 机电材料：业务调整、设备报废、起订量采购、物料替换、材料退回。

“暂时留存”仅属于静态材料处理方案；新增静态物料系统导入时沿用“材料替换”的导入路径、校验和字段规则。

## 7.2 警报级别配置

配置中心新增“警报级别”页签，独立于静态材料/机电材料配置，不进行启用、停用或其他状态管控。表格字段顺序固定为：警报级别、严重度、留存率、静态月数、操作。留存率和静态月数不保存自由文本，而保存最小值、最大值以及分别对应的 `minBoundary`、`maxBoundary`：`open`（开区间）或 `closed`（闭区间）。编辑时最小值、最大值前各有一个仅包含“开区间”“闭区间”的下拉；页面根据两端结构化字段生成括号区间展示文本。相邻区间共享边界时，仅当左侧最大值和右侧最小值都选择闭区间才视为重叠；内部范围重叠或区间起止值无效时阻止保存并提示具体档位，后端可直接按 JSON 数值和区间类型解析。

| 警报级别 | 严重度 | 留存率 | 静态月数 |
| --- | --- | --- | --- |
| `-` | 正常 | `<30%` | `≤3个月` |
| 3级 | 预警 | `30%<留存率<50%` | `4个月<静态月数<6个月` |
| 2级 | 警告 | `50%<留存率<60%` | `7个月<静态月数<9个月` |
| 1级 | 高危 | `≥70%` | `≥10个月` |

1. 仅留存率和静态月数允许编辑修改，警报级别和严重度为只读展示。
2. 编辑保存后写入本地配置，并同步警报分析页右侧警报标准、留存率/静态月数筛选项及风险判定口径。
3. 新增静态物料前 2 个月仍为缓冲期，从第 3 个月开始计算警报；不同维度跨区间时取风险更高等级。

## 7.3 静态月数配置

静态月数直接按日期计算，不使用“开发类型 + 材料类别”的配置基数，不建设静态月数配置入口。

# 8. 导入、导出与权限

## 8.1 导入通用要求

1. 导入弹窗提供模板下载区域、文件选择区、导入确认和取消。
2. 模板必须包含工厂编码、工厂描述、物料编码、物料描述；新增静态物料表两个Tab的模板还必须在责任单位后包含静态提出日期。
3. 除新增静态物料表外，其他导入按工厂编码 + 物料编码更新；新增静态物料表按物料编码 + 分厂编码（工厂编码） + 静态提出日期更新。工厂描述、物料描述不参与唯一键匹配，也不通过导入更新。
4. 下拉字段只能使用当前材料类型对应配置中的启用值。
5. 导入失败需返回行号、工厂编码、物料编码、字段名和失败原因，并支持查看或下载错误明细。
6. 超出处理方案变更次数的记录必须明确提示，不能静默跳过。
7. 处理方案模板下载前必须完成开发类型和责任单位完整性校验；错误提示中的物料编码去重并以中文逗号分隔。
8. 静态材料责任单位导入模板同时包含开发类型和责任单位。当前记录只要开发类型或责任单位为空，就进入待导入数据；导入时两列均不能为空，开发类型仅允许板木、软体、定制；机电材料模板不含开发类型。两个Tab均按物料编码 + 分厂编码（工厂编码） + 静态提出日期更新。
9. 新增静态物料表静态材料、机电材料两个Tab的导入模板均在责任单位列后增加静态提出日期；模板字段顺序固定，不允许调整列顺序。新增静态物料导入按“物料编码 + 分厂编码（工厂编码） + 静态提出日期”判断唯一性，批次内重复或缺少任一键值时整批阻止导入。
10. 所有模板和查询结果导出文件固定字段顺序。导出文件中由系统查询得到的数据列全部锁定不可修改；导入模板仅开放业务维护字段，系统识别字段和静态提出日期锁定。导入时校验表头名称及顺序，发生变更即阻止导入并提示按模板恢复。

## 8.2 导出

各报表支持按当前筛选范围导出，暂不设置导出字段、记录数或文件大小限制。导出字段严格按页面列表顺序生成，列顺序固定；查询结果的全部数据列启用工作表保护，不允许修改。

## 8.3 权限与审计

新增静态物料表的数据导入和开发类型小铅笔维护必须设置角色权限管控。所有业务维护记录操作人、操作时间及变更前后值；审计日志不设置清理期限。历史业务版本永久保留。

# 9. 验收标准

1. 报表中心存在“静态材料分析”子菜单并展示 7 个报表入口。
2. 新增静态物料表包含静态材料、机电材料两个 Tab，字段及筛选随 Tab 切换。
3. 所有记录按工厂编码 + 物料编码分开展示，不合并不同工厂数据；仅新增静态物料表导入按物料编码 + 分厂编码（工厂编码） + 静态提出日期判断唯一性。
4. 静态提出日期固定每月 1 日，默认当前月，选择全部时间可查询全量历史。
5. 两张消耗报表均由新增静态物料表供数并展示工厂描述。
6. 静态材料和机电材料导入模板均包含工厂、物料编码及描述；机电处理方案和原因下拉仅取机电启用配置。
7. 新记录处理方案默认方案待定；生产留用和售后留用必须填写留用数量，其他方案不能填写留用数量、留用时间。
8. 开发新品、开发特款填写预计打样完成时间；其他方案填写预计消耗完成时间。
9. 处理方案和处理意见存在变更时显示橙色字体，点击任一字段可查看完整历史。
10. 开发类型支持系统计算、独立导入和铅笔入口页面维护，页面编辑具备保存、取消交互。
11. 同月重复传输的静态/机电新增数据不得产生重复生效记录；具体技术处理由开发任务定义，不建设 Yolink 通知。
12. 战略/专项备料时3月月均消耗量在连续维护周期内保持首次值，移除后重新纳入时使用新周期首次值。
13. 看板按记录数统计，同一物料在不同工厂分别计数，处理方案分析默认生产留用。
14. 开发类型按工厂编码 + 物料编码逐条计算，同一条记录只产生一个开发类型，无需设置多个开发类型的优先级。
15. 材料类别按物料组规则生成：`RA11*` 取描述第 3 层，`RB*`、`RC*` 取第 1 层，其余取第 2 层；皮料示例结果与第 5.1 节一致。
16. 新增静态物料表静态材料、机电材料两个 Tab 及两张消耗跟踪表，均在物料描述后展示“产生类型”；该字段由 SAP 接口回传，取值仅为定性或定量且不得为空。
17. 两张消耗跟踪报表不提供“现可用库存是否为 0”查询条件。

# 1. 概述

## 1.1 背景

静态材料分析由报表中心、分析看板和配置中心三部分组成。新增静态物料表是静态材料及机电材料跟踪消耗报表的基础数据来源；战略/专项备料、基础数据及静态材料、机电材料相关数据均由外围系统集成提供。

外围系统在每月 1 日执行一次取数并传输数据。IOC 需要保留每次传输的月度数据快照，在此基础上提供查询、手工维护、处理方案变更追溯、消耗跟踪、预警分析和配置管理能力，避免业务线继续以分散 Excel 作为唯一管理方式。

本需求基于当前已确认原型、菜单截图及下列接口资料文件名整理：

- `战略和专项材料SAP接口字段.xlsx`
- `战略和专项材料基础数据SAP接口字段.xlsx`
- `机电材料SAP接口字段.xlsx`
- `静态材料SAP接口字段.xlsx`

> 注：上述文件为 E-SafeNet 封装格式。已尝试通过本机 Excel 以只读、禁用宏、禁用链接更新、关闭不保存的方式读取；后台 Excel 等待 120 秒仍未返回工作簿内容，源文件未被修改。字段级映射待 E-SafeNet 在可见 Excel 会话中完成授权打开后继续补全。

## 1.2 范围

**本期范围：**

- 建立外围系统到 IOC 的月度基础数据集成规则、传输版本及异常处理要求。
- 建立“静态材料分析”菜单下 7 个功能入口的数据来源、查询展示及手工维护边界。
- 建立分析看板“静态材料处理跟踪分析”的统计与下钻数据来源要求。
- 建立配置中心“静态材料配置”的基础配置及其对导入、维护、查询的生效规则。
- 明确处理方案类型、处理意见、开发类型的导入与人工维护规则，以及变更追溯要求。

**不在本期范围：**

- 改造外围 SAP 或外围系统的取数程序。
- 在 IOC 页面中直接写回 SAP 或外围系统。
- 未确认公式的前端固化计算；所有未确认公式暂以接口入参或“待确认”处理。
- 替代业务线审批流、权限流或真实文件导出引擎。

**边界说明：**

- 外围系统负责每月 1 日生成并传输基础数据；IOC 负责接收、校验、留存版本、展示、业务补录和衍生分析。
- 外围数据以“工厂编码 + 物料编码”为最小业务记录粒度；不同工厂的同一物料编码不得合并展示或相互覆盖。
- 机电材料跟踪消耗报表、静态材料跟踪消耗报表的数据来源为“新增静态物料表”经维护后的数据，不直接以独立人工台账作为来源。

# 2. 功能需求

## 2.1 业务流程

```text
外围系统每月1日生成数据
  -> 传输至 IOC 接口接收区
  -> IOC 校验文件/字段/记录唯一键
  -> 生成当月传输版本与接收结果
  -> 写入新增静态物料基础数据
  -> 业务线导入或页面维护处理方案、处理意见、开发类型等维护字段
  -> 静态/机电消耗报表、预警表及分析看板基于该数据查询、统计与下钻
```

## 2.3 详细功能描述

### 2.3.1 外围数据集成与月度版本

#### 2.3.1.1 月度数据接收

**功能描述：**

1. 外围系统在每月 1 日传输战略和专项材料、战略和专项材料基础数据、机电材料、静态材料四类数据。
2. IOC 对每次传输生成独立版本，至少记录数据类型、数据月份、传输时间、传输状态、总记录数、成功数、失败数、失败原因。
3. 静态提出日期固定为数据月份的 1 日；查询默认当月，允许选择“全部时间”查询历史月度快照。
4. 战略备料及专项备料基础数据按传输版本更新，每次传输均生成并保存独立版本号，支持查询历史版本及切换当前查看版本。
5. 新增静态材料数据每月仅允许成功接收一次。同一月份发生第 2 次及以上传输时，数据写入临时表，不进入正式业务表；该批次标记为失败并发送 Yolink 消息通知。
6. 数据接收成功后，向对应报表和分析数据集提供可查询的当月数据；失败时不得以部分错误数据覆盖已生效快照。

**校验条件：**

| 校验项 | 要求 | 失败处理 |
| --- | --- | --- |
| 数据月份 | 必填，且应为每月 1 日对应月份 | 拒绝该次传输并返回错误 |
| 工厂编码 | 基础数据涉及工厂维度时必填 | 记录错误明细，处理方式待确认 |
| 物料编码 | 基础数据涉及物料维度时必填 | 记录错误明细，处理方式待确认 |
| 唯一键 | 工厂编码 + 物料编码在同一快照内唯一 | 重复处理规则待确认 |
| 接口字段 | 以最终确认的接口字段清单为准 | 缺失字段拒绝传输 |
| 新增静态材料同月重复传输 | 同一月份仅允许一次成功传输 | 写入临时表、批次报错并发送 Yolink 消息通知 |

**验收标准：**

- 每月可查询到对应月份的传输版本及接收状态。
- 异常传输可定位到数据类型、月份、失败原因及问题记录。
- 同一物料编码在不同工厂的记录独立留存与展示。
- 查询某月份时，仅使用该月份对应的生效快照。
- 战略备料及专项备料基础数据的每次传输均可通过版本号追溯。
- 新增静态材料同月重复传输不会进入正式业务表，可在临时表定位问题批次，并能收到 Yolink 异常通知。

### 2.3.2 报表中心 - 静态材料分析

#### 2.3.2.1 菜单与数据来源

“报表中心 > 静态材料分析”下展示以下 7 个入口：

| 菜单 | 数据来源 | 核心用途 | 状态 |
| --- | --- | --- | --- |
| 战略备料表 | 战略和专项材料 SAP 接口 | 查询战略备料物料库存、消耗及静态数量 | 已确认名称，字段映射待确认 |
| 专项备料表 | 战略和专项材料 SAP 接口 | 查询专项备料物料库存、消耗及静态数量 | 已确认名称，字段映射待确认 |
| 战略和专项材料基础数据 | 战略和专项材料基础数据 SAP 接口 | 展示战略/专项材料的基础明细 | 已确认名称，字段映射待确认 |
| 新增静态物料表 | 静态材料 SAP 接口、机电材料 SAP 接口 | 静态和机电材料的基础数据、业务维护入口 | 已确认 |
| 机电材料跟踪消耗报表 | 新增静态物料表的机电材料数据 | 查询处理方案和消耗执行情况 | 已确认 |
| 静态材料跟踪消耗报表 | 新增静态物料表的静态材料数据 | 查询处理方案和消耗执行情况 | 已确认 |
| 静态物料警报表 | 新增静态物料表及警报规则 | 识别高库龄、高留存风险物料 | 已确认，公式待确认 |

#### 2.3.2.2 战略备料表与专项备料表

**查询条件：**材料类别、物料编码、物料描述、备料天数、可供应天数。

**列表展示：**材料类别、物料编码、物料描述、备料时 3 月月均消耗量、备料天数、当前库存、近 3 月月均消耗量、可供应天数、超量备料。

**规则：**

- 战略备料与专项备料字段、查询逻辑、操作方式一致，仅数据类型不同。
- 报表默认查询当前生效数据版本；版本查看与历史月度查询的关系待确认。
- 当前库存从 IOC 库存数据获取，按工厂编码 + 物料编码匹配。
- 近 3 个月月均消耗量、静态数量由 SAP 接口提供。
- 可供应天数 = 当前库存 / 近 3 个月月均消耗量；除数为 0、结果精度及单位换算规则待确认。

#### 2.3.2.3 战略和专项材料基础数据

**功能描述：**

- 展示外围系统传输的战略和专项材料基础数据，作为战略备料表和专项备料表的业务基础明细。
- 支持按照最终确认的关键业务字段查询、重置、导出和分页。
- 基础数据字段、是否支持人工维护、与战略/专项报表字段的关联关系待确认。

#### 2.3.2.4 新增静态物料表

**页签：**静态材料、机电材料。

**共同规则：**

- 默认按静态提出日期的当前月查询；静态提出日期固定为每月 1 日。
- 支持“全部时间”，用于查询所有已生效月度数据。
- 表格按工厂编码 + 物料编码分开展示，禁止跨工厂合并。
- 工厂编码 + 物料编码为业务维护和导入更新唯一键；工厂描述、物料描述用于核对。
- 表格工具栏提供导入、导入开发类型、导出；不展示“查询结果”文字。

**静态材料列表字段：**

物料编码、物料描述、材料类别、物料组、物料组描述、工厂编码、工厂描述、开发类型、单位、现可用库存、供应商未交量、计划需求量、应消耗量、静态提出日期、近一年入库量、近一年出库量、责任单位、静态原因、处理方案类型、处理意见、预计消耗完成时间、留用数量、留用时间、预计打样完成时间。

**机电材料列表字段：**

物料编码、物料描述、物料组、物料组描述、工厂编码、工厂描述、单位、应消耗量、静态提出日期、近一年入库量、近一年出库量、责任单位、静态原因、处理方案类型、处理意见、留用数量、留用时间。

**业务维护字段与规则：**

| 字段 | 来源/维护方式 | 规则 |
| --- | --- | --- |
| 处理方案类型 | 新数据默认值 + 业务导入 | 未导入时默认“方案待定”；业务导入后以导入值为准 |
| 处理意见 | 业务导入 | 与处理方案类型一并记录变更历史 |
| 留用数量 | 业务导入 | 仅处理方案为“生产留用”或“售后留用”时允许填写；其他方案为空 |
| 预计消耗完成时间 | 业务导入 | 处理方案为“开发新品”或“开发特款”时为空；其他处理方案必须填写 |
| 预计打样完成时间 | 业务导入 | 仅处理方案为“开发新品”或“开发特款”时必须填写；其他处理方案为空 |
| 责任单位 | 业务导入 | 值域及必填规则待确认 |
| 静态原因 | 业务导入/配置选择 | 必须从配置中心下拉选项选择 |
| 开发类型 | 系统计算、独立导入或页面维护 | 规则见下文 |
| 当前库存 | IOC 库存数据 | 按工厂编码 + 物料编码获取，不跨工厂合并 |
| 计划需求量 | SAP 接口 | 由外围系统数据集成提供 |
| 供应商未交量 | SAP 接口 | 由外围系统数据集成提供，不进入业务导入模板 |

**开发类型规则：**

- 6199：板木；6299：软体；8599：定制。
- 8699：物料描述包含“定制”时为定制，否则为板木。
- 潜江、清丰与总公司相同物料编码时，继承总公司对应开发类型。
- 不满足系统规则时为空，由业务单独导入或页面维护。
- 已维护值默认只展示文本，点击后才进入下拉编辑；未维护值直接展示下拉框。
- 下拉选项仅为板木、软体、定制；保存生效，取消恢复原值。
- 开发类型导入模板必须包含：工厂编码、工厂描述、物料编码、物料描述、开发类型；按工厂编码 + 物料编码更新。

**处理方案变更控制：**

- 处理方案类型和处理意见必须按工厂编码 + 物料编码记录每次更新。
- 两字段中任一存在变更历史时，列表对应值使用橙色字体提示，背景色不变；点击查看变更弹窗。
- 变更弹窗展示：处理方案类型、处理意见、更新人、更新时间。
- 处理方案类型/处理意见累计最多更新 2 次；第 3 次导入更新必须报错并阻止本次导入。

#### 2.3.2.5 静态材料与机电材料跟踪消耗报表

**共同规则：**

- 数据来源为新增静态物料表对应页签的已生效数据及业务维护字段。
- 支持按静态提出日期（月，默认当月）、物料编码、处理方案类型及当前报表适用维度查询。
- 两张报表均展示处理方案类型、处理意见及其变更历史；点击有历史记录的值可查看记录。
- 仅生产留用、售后留用记录展示留用数量、留用时间；其余方案为空。

**机电材料跟踪消耗报表查询条件：**静态提出日期、工厂描述、物料编码、对应开发、材料类别、处理方案类型、现可用库存是否为 0。

**静态材料跟踪消耗报表查询条件：**静态提出日期、工厂描述、开发类型、材料类别、物料编码、处理方案类型、现可用库存是否为 0。

**机电材料跟踪消耗报表字段：**物料编码、物料描述、工厂描述、对应开发、材料类别、单位名称、提报时库存量、现可用库存、应消耗总量、静态提出日期、现库存量、是否入库、入库数量、责任单位、静态原因、处理方案类型、处理意见、留用数量、留用时间、总出库量、出库比例。

**静态材料跟踪消耗报表字段：**物料编码、物料描述、工厂描述、开发类型、材料类别、单位、提报时库存量、现可用库存、供应商未交量、计划需求量、应消耗总量、静态提出日期、处理方案类型、处理意见、静态月数、入库数量、总出库量、留存比例、留用数量、留用时间、预计打样完成时间、预计消耗完成时间。

**已确认计算规则：**

- 静态材料总应消耗静态量 = 提报静态库存量 + 供应商未交量 - 计划需求量。该公式业务标记为“待定”，在最终确认前需支持调整，不作为不可变规则。
- 机电材料总应消耗静态量 = 提报静态库存量。
- 出库比例 =（总应消耗静态量 - 现有库存）/ 总应消耗静态量。
- 留存率 = 现有库存 / 总应消耗静态量。
- 库龄按静态提报时间跨月计算完整自然月数，不计算当前未完整月中的天数。例如 8 月 1 日提报，10 月 13 日查询，库龄为 2 个月。

**仍待确认来源字段：**查询期间出库量、总出库量、最后出库日期、最后领用分厂、是否入库、入库数量。

#### 2.3.2.6 静态物料警报表

**查询条件：**工厂、对应开发、材料类别、物料编码、处理方案类型、静态月数区间、留存率区间、警报级别。

**列表字段：**工厂、材料类别、库存地点、物料编码、物料名称、对应开发、应消耗总量、现可用库存、单位、静态原因、处理方案类型、留用数量、留用时间、处理意见、总出库量、出库比例、留存率、警报级别、呆滞提出时间、静态月数。

**已确认警报分档：**

| 警报级别 | 留存率 | 可用月份/库龄条件 | 展示颜色 |
| --- | --- | --- | --- |
| 6级正常 | 小于 30% | 可用月份不超过 9 个月 | 绿色 |
| 3级预警 | 30% - 50% | 10 - 12 个月 | 黄色 |
| 2级警报 | 50% - 60% | 13 - 15 个月 | 橙色 |
| 1级高危 | 大于等于 60% | 16 个月以上 | 红色 |

跨区间时按较高风险等级显示。留存率 = 现有库存 / 总应消耗静态量；库龄按静态提报日期跨月计算完整自然月数。分母为 0、显示精度及边界归属仍待确认。

### 2.3.3 分析看板 - 静态材料处理跟踪分析

**功能描述：**

- 分析看板提供“静态材料处理跟踪分析”入口，基于新增静态物料表及两张消耗报表的生效数据展示总体分析、警报分析、处理方案分析和材料明细。
- 总体分析按全部、定制、软体、板木展示，并按警报级别与处理方案统计数量、合计和占比。
- 警报分析、处理方案分析按开发类型、留存率、库龄交叉统计；点击统计数可下钻至材料明细并携带当前筛选条件。
- 看板筛选至少包含时间、库龄、留存率；处理方案分析默认选中“生产留用”。

**统计口径：**看板中的数量按工厂编码 + 物料编码记录数统计；同一物料在不同工厂分别计 1 条。分组占比以当前筛选范围内对应分组的总记录数为分母。

### 2.3.4 配置中心 - 静态材料配置

**功能描述：**

- 配置中心提供“静态材料配置”入口，包含“处理方案配置”和“静态原因配置”两个页签。
- 两类配置均支持按名称、状态查询与新增；已存在名称不可修改，仅可切换生效/失效。
- 生效配置项可用于新增静态物料表的导入校验、下拉选择和报表筛选；失效项保留历史展示，不可用于新增维护。
- 处理方案和静态原因均按“静态材料、机电材料”分开配置；机电材料导入只能使用对应机电配置页的启用项，不得引用静态材料配置值。
- 新增机电材料导入模板中“处理方案类型”“静态原因”均为 Excel 下拉选择，选项实时取对应机电配置页启用项；配置外值导入时报错并阻止提交。

**初始处理方案：**生产留用、售后留用、材料替换、采购退货、报废变卖、开发新品、开发特款。

**初始静态原因：**采购大于需求、计划大于需求、样品采购、首批采购、起订量采购、停单扣款、节约退料、物料替换、分厂需求、计划取消、业务调整、设备报废、常规备料、战略备料、专项备料。

## 3.2 字段映射原则

- 接口原始字段、IOC 落库字段、展示字段、计算字段、业务维护字段必须在字段映射表中逐项标识。

- 工厂编码、物料编码、数据月份为跨数据集关联的基础字段；不足时不得通过物料描述等文本字段进行模糊匹配。
- 工厂描述、物料描述用于业务核对与模板展示，不作为更新唯一键。
- 接口未提供但需展示的计算字段，必须明确计算公式、源字段、精度、为空/除零/跨月处理规则。

| 场景 | IOC 处理要求 |

# 4. 验收标准

- 外围系统每月 1 日传输的四类数据可在 IOC 留存传输版本，并按月份查询。
- 战略备料及专项备料基础数据每次传输均生成并保存版本号，可查看历史版本。
- 新增静态材料每月只允许一次成功传输；同月重复传输进入临时表、正式表不变，并触发 Yolink 异常消息。
- 战略备料表、专项备料表、战略和专项材料基础数据、新增静态物料表、两张消耗报表、警报表均能追溯至明确的数据来源。
- 新增静态物料表按工厂编码 + 物料编码分开展示；导入更新不跨工厂覆盖。
- 静态材料和机电材料导入模板均包含工厂编码、工厂描述、物料编码、物料描述；更新键为工厂编码 + 物料编码。
- 机电材料、静态材料跟踪消耗报表均展示工厂描述；记录仍按工厂编码 + 物料编码区分，不跨工厂合并。
- 静态提出日期默认查询当月且记录日期为每月 1 日；勾选“全部时间”可查询全量历史数据。
- 未维护处理方案的新数据默认显示“方案待定”。
- 仅生产留用、售后留用可维护留用数量/留用时间；其他方案字段为空。
- 机电材料导入模板的处理方案类型、静态原因均以下拉方式填写，且只能选择配置中心对应机电材料配置页的启用项。
- 开发新品、开发特款必须填写预计打样完成时间并清空预计消耗完成时间；其他处理方案必须填写预计消耗完成时间并清空预计打样完成时间。
- 处理方案类型和处理意见保留最多两次更新历史；超过两次的导入被阻止并给出明确错误。
- 开发类型系统规则、独立导入与页面维护均按已确认规则执行，且不提供“未维护”作为维护下拉项。
- 所有计算字段均有经业务确认的字段来源、计算公式、边界条件和验收样例。

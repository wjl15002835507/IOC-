计算规则

  • 留存率 = 现库存数量 / 提报呆滞时数据；出库比例为 1 - 留存率。
  • 留存率级别与库龄级别共同映射为 1、2、3、6 四档；1级标识高危，2级标识警报，3级标识预警，6级标识正常。
  • 总览与分析矩阵均按“物料编码计数”展示，不将库存数量相加作为材料项数。

原型范围

本次呈现

  • IOC 顶部栏、侧边导航、面包屑和安全水印。
  • 全局筛选：开发类型、警报级别、处理方案、库龄、留存率多选、月份；材料明细页额外显示物料关键词；支持查询和重置。

  • 留用售后：1,553 项专项视图，展示三类开发的结构和风险矩阵。
  • 材料明细：Excel 字段的代表性脱敏数据、横向滚动、分页、列显隐、查看详情抽屉和导出提示。

本次不呈现

  • 对 Excel 源文件的写回、警报规则配置、材料处理审批及跨系统跳转。

# 新供应商开发进度跟踪（移动端）

## 需求

- 目标用户：需要查询新引进供应商进度及下单表现的 IOC 使用人员。
- 核心任务：按引进时间、下单时间和供应商筛选 SRM 同步数据，查看供应商下的物料订单次数和下单数量。
- 数据来源：SRM，数据已集成。当前原型使用标注为示例的本地模拟数据，不连接接口。
- 统计口径：默认引进时间和下单时间均为近三个月，两个时间范围独立筛选。按供应商和物料分组，正式下单按采购订单号计次，下单数量显示物料单位。只统计供应商成为正式供应商之后的订单。
- 页面范围：筛选弹窗、查询、重置和结果查看。不提供导出或供应商详情。
- 开发节点：展示业务需求、采购开发、核价完成和正式供应商节点。前三个节点的数据目前缺失，正式供应商日期节点待业务确认。

## 页面与交互

- 页面整体按用户截图布局：顶部设备状态栏、6px 青绿色分隔条、居中标题、整行浅灰筛选栏，以及青绿色粗边框的数据面板；数据面板内供应商信息使用浅薄荷色，物料列头使用浅灰底。
- 不增加未确认的引进周期下拉或供应商/开发/下单分类标签。
- 页面头部使用居中标题；筛选条件在整行浅灰栏中单行排列，包含窄供应商输入框、两个时间范围条件及漏斗按钮。供应商结果位于下方青绿色粗边框面板内，供应商浅薄荷色分组行和浅灰物料列头分层呈现。
- 供应商条件使用常驻输入框，点击查询或按回车后按名称模糊搜索，并兼容供应商编码。
- 引进时间和下单时间快捷入口显示在筛选面板中，分别打开对应时间条件。
- 当前已应用的供应商关键词或时间范围使用橙色，未设置的供应商关键词使用灰色。默认近三个月日期范围已应用，因此时间条件默认显示橙色。
- 引进时间和下单时间各自提供快捷范围按钮与可手动调整的起止日期。快捷范围包含近1个月、近3个月、近6个月、近1年和自定义，默认近3个月；切换快捷范围同步更新该条件的起止日期，手动修改日期转为自定义。
- 筛选入口打开居中弹窗，使用暗色遮罩、青绿色标题栏和关闭按钮。
- 弹窗底部提供重置和确认操作。重置恢复默认值但保留弹窗，确认应用条件并关闭，关闭或点击遮罩放弃未确认修改。
- 结果按供应商分组显示引进日期、开发节点和按物料汇总的下单次数及数量。
- 查询使用确认后的筛选条件刷新结果，重置恢复近三个月默认日期和空供应商关键词。
- 空结果时显示无匹配记录。

## 设计

- 按用户提供的移动端截图匹配页面结构和颜色，包括白色主底色（#FFFFFF）、浅灰筛选栏（#F1F1F1）、浅灰物料表头（#EEEEEE）、青绿色分隔条（#0DB591）、青绿色数据面板边框（#0BB78F）及浅薄荷色供应商信息区（#F1FCF8）。
- 保留兑油移动端的青绿色选中态与查询按钮、适合触屏的控件尺寸。
- 数据以供应商行组和节点进度横排呈现，物料名称、次数、数量在手机窄屏下保持可读。
- 模拟日期和待确认状态须在页面内明确标识。

# 静态材料库龄配置主规格补充
## 产品需求
- 入口：IOC 公共菜单“配置中心 → 静态材料库龄配置”。
- 规则按开发类型隔离；材料类别可配置具体类别或“全部”。
- 同一开发类型下优先使用具体材料类别规则，没有时回退到“全部”。
- 支持按开发类型、材料类别联动筛选，支持新增与编辑。
- 下拉选项来自当前静态材料数据的开发类型与材料类别，支持输入检索。
## 设计与交互
- 延续 IOC 公共外壳、绿色侧栏和紧凑表格风格。
- 页面结构为标题说明、筛选栏、配置表格；新增/编辑使用居中弹窗。
- 表格示例列出呆滞提出时间 2026/06/02 加基数后的实际库龄，帮助校验规则。
## 实施边界
- 本轮为可运行原型，配置数据保存在页面状态中，不接后端接口。
- 基数单位为月，计算展示使用当前原型基准日期 2026/07/10。
- 不修改订单跟踪和静态材料分析既有数据逻辑。
## 验收重点
- 菜单悬浮显示配置中心子入口并可打开页面。
- 开发类型、材料类别筛选可组合使用；重置恢复全部。
- 新增、编辑后表格立即更新；“全部”规则可作为兜底规则展示。

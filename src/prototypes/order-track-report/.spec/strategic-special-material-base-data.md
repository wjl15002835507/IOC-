# 战略和专项材料备料基础数据

## 状态

主规格草案。用于确认首版报表信息架构与查询口径，尚未替代接口字段映射文档。

## 目标与边界

- 菜单位置：报表中心 > 静态材料分析 > 战略和专项材料备料基础数据。
- 数据由外围系统全量传输；每一笔成功传输生成一个不可覆盖的数据版本。
- SAP 每次全量传输均包含“备料时 3 月月均消耗量”，供战略备料表和专项备料表生成冻结基准值；基础数据版本页保留每版接口原始值。
- 用户可按版本查询当次快照，查看传输时间、传输状态和记录数，并导出当前查询结果。
- 本版为可运行原型，展示的是模拟快照数据，不实施真实接口、持久化、权限或实际文件导出。

## 首版页面

- 筛选条件：数据版本、物料编码、物料描述、物料类型、状态、对比上次版本。
- 版本记录抽屉：展示版本号、传输时间、记录数、状态；可切换版本。
- 表格字段：物料编码、物料描述、物料类型、备料周期、引用单位、创建日期、创建人、状态、对比上次版本、版本号。
- 工具栏：显示当前版本及“全量快照”标识，提供版本记录与导出操作。

## 传输与版本口径

- 每次外围系统全量传输成功后，按传输完成时间生成版本号；建议格式 `VyyyyMMdd-序号`。
- 查询时只能读取指定版本的快照，不与其他版本拼接。
- 重传成功生成新版本，不覆盖既有历史版本。
- 失败传输不生成可查询的数据快照；正式实现是否保留失败日志需在接口方案中确认。

## 版本比对与“对比上次版本”字段

- “对比上次版本”不是外围接口原始字段，由系统使用当前查询版本与其紧邻上一成功版本进行比对后生成。
- 当前版本存在、上一版本不存在的物料编码，显示“新增”。
- 上一版本存在、当前版本不存在的物料编码，作为补充行返回，状态显示“失效”，显示“移除”。
- 两个版本均存在的物料编码，显示“保持”；本版未定义修改识别。
- 首个成功版本无上一版本，该字段留空。

## 备料时 3 月月均消耗量

- SAP 以物料第一次维护为战略或专项材料的日期为基准，向前取 3 个月计算平均消耗量，并在每次基础数据全量传输中提供该值。
- IOC 按物料编码 + 物料类型识别连续维护周期。连续成功版本中始终存在时，战略/专项报表固定展示本周期首次接收值，不被后续版本值覆盖。
- 某次成功全量版本中不再存在即视为移除并结束当前周期；后续重新纳入时建立新周期，取重新纳入版本的接口值作为新的冻结展示值。
- 失败批次不参与连续性判断；各版本接口原始值仍按版本保留，用于追溯。

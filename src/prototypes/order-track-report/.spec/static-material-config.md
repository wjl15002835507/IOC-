# 静态材料配置主规格补充

## 产品需求

- 入口：IOC 公共菜单“配置中心 -> 静态材料配置”。
- 页面提供“处理方案配置”和“静态原因配置”两个 tab；每个配置页下均有“静态材料”和“机电材料”页签。
- 处理方案初始项：静态材料为生产留用、售后留用、材料替换、暂时留存、采购退货、报废变卖、开发新品、开发特款；机电材料为生产留用。
- 静态原因初始项：静态材料为采购大于需求、计划大于需求、样品采购、首批采购、起订量采购、停单扣款、报废拆件、材料退回、物料替换、分厂需求、计划取消、业务调整、设备报废、常规备料、战略备料、专项备料；机电材料为业务调整、设备报废、起订量采购、物料替换、材料退回。
- 配置中心新增独立“责任单位”页签，不区分材料类型；当前涵盖 55 个责任单位，名称清单以需求文档 V3.10 的“当前涵盖责任单位（55项）”为准：采购二部、采购一部、板木工艺部、板木设计部、订单技术部、定制工程设计部、定制设计部、床垫开发部、电商开发部、软体工艺部、软体开发部、监察部、内控部、八分厂、备料分厂、二分厂、六分厂、十二分厂、实木八厂、实木六厂、实木七厂、实木三厂、实木五厂、定制八厂、定制橱柜二厂、定制九厂、定制六厂、定制门板二厂、定制门板一厂、定制七厂、定制十厂、定制五A厂、定制五B厂、潜江定制厂、潜江沙发厂、清丰定制厂、清丰沙发厂、绷皮厂、床垫厂、功能沙发厂、软床厂、软床二厂、沙发八厂、沙发二厂、沙发九厂、沙发六厂、沙发七厂、沙发五厂、沙发一厂、材料管理部、机电工程部、计划管理部、技改车间、压贴二厂、压贴三厂。
- 两类配置均可按名称和状态查询，可新增；既有名称没有编辑或删除入口，名称不可修改，只能切换“已启用/未启用”状态，操作文案为“停用/启用”。
- 责任单位可按名称和状态查询、新增；新增时填写部门名称和状态，状态默认“已启用”，名称不可修改、不物理删除，操作列支持“停用/启用”。业务报表责任单位筛选条件支持输入关键字模糊搜索下拉，从已启用责任单位中筛选后选择，“全部”清空筛选；失效责任单位不进入任何下拉选择、模板校验或业务导入值域；历史业务数据仍可展示原值。
- 配置中心增加“警报级别”页签，展示四档警报级别、严重度、留存率和静态月数；列顺序为警报级别、严重度、留存率、静态月数、操作。警报级别和严重度只读，留存率与静态月数统一使用最小值、最大值以及最小值、最大值各自的区间类型编辑保存，不保存自由文本，不进行状态管控，后端可直接解析结构化配置。
- 警报规则的最小值和最大值前分别提供“开区间/闭区间”下拉选择；非编辑态按两端选择展示对应括号，并通过颜色区分开闭状态，悬停可查看“包含/不包含”端点说明。相邻区间共享边界时，仅当两端都包含该边界才视为重叠；区间内部相交均视为重叠。保存时留存率和静态月数分别校验最小值小于最大值，存在重叠或无效区间时阻止保存并提示具体档位。
- 警报级别页签不显示独立的标题或说明块，页签下方直接展示配置表格。
- 静态材料与机电材料配置值域相互隔离；机电材料的处理方案、静态原因只能取对应机电材料页签中的启用项。
- 新增静态材料和机电材料导入模板的“处理方案类型”“静态原因”列均使用 Excel 下拉选择，下拉值实时读取对应材料类型的启用配置项。
- 所有涉及责任单位的查询条件、页面维护和 Excel 导入模板均使用责任单位配置的启用项下拉；业务报表责任单位数据行点击编辑后与筛选条件使用同款可输入模糊搜索下拉，编辑态不提供“全部”，只能选择启用项；静态材料模板责任单位列位于开发类型之后、静态提出日期之前，机电材料模板责任单位列位于物料描述之后、静态提出日期之前；失效项不可选择和导入。
- “暂时留存”仅属于静态材料处理方案；新增静态物料系统导入时，按“材料替换”使用同一套处理方案导入路径、校验和字段规则。
- 分析看板的处理方案统计矩阵、处理方案分析图例和处理方案筛选项包含“暂时留存”；当前无对应材料数据时显示为 0，不改变既有总计。

## 设计与交互

- 复用 IOC 绿色导航外壳、紧凑页签、筛选条和浅灰表头。
- 新增采用居中弹窗，提示名称不可修改；名称为空或与当前配置重复时给出即时提示。
- 原型数据保存于浏览器本地状态，不接后端接口；新增、启停配置后，后续下载的相应材料导入模板同步更新下拉值。

## 验收重点

- `?view=static-config` 可打开新页面，菜单悬浮项可进入该页面。
- 静态材料处理方案显示 8 条，机电材料处理方案显示 1 条；静态材料静态原因显示 16 条，机电材料静态原因显示 5 条。
- 责任单位页签默认显示 55 条初始部门；可新增并设置状态，失效项不可出现在责任单位下拉和导入模板校验值域。
- 新增、名称重复拦截、生效/失效切换均即时反映到表格。
- 警报级别配置默认展示“- / 正常、3级 / 预警、2级 / 警告、1级 / 高危”四档，留存率和静态月数编辑保存后即时反映。
- 下载新增静态物料模板后，“暂时留存”可作为处理方案类型选择，且与“材料替换”执行相同的导入校验与更新规则。
